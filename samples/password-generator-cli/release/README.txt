==================================================
Password Generator CLI
==================================================

Windows向けのパスワード生成ツール（CLI）です。
本ツールは Python で作成し、Nuitka により実行ファイル化しています。

--------------------------------------------------
用途について
--------------------------------------------------
・個人利用、学習用途向けのパスワード生成ツールです。
・本ツールで生成したパスワードの安全性を保証するものではありません。
・重要なシステムや業務用途での使用は、ご自身の判断で行ってください。

--------------------------------------------------
起動方法
--------------------------------------------------
1) コマンドプロンプトを開く
2) app フォルダへ移動
   cd app
3) 実行例
   passgen.exe -l 20 -k digits lower upper symbols -n 3

--------------------------------------------------
主なオプション
--------------------------------------------------
-l / --length : パスワード長（例：20）
-n / --count  : 生成する個数（例：3）

-k / --kinds  : 使用する文字種を指定します（複数指定可）
  digits  : 数字（0-9）
  lower   : 英小文字（a-z）
  upper   : 英大文字（A-Z）
  symbols : 記号（!@#$%^&* など）

※ symbols を指定しない場合、記号は含まれません

--------------------------------------------------
簡単な使い方（まずはこれだけ）
--------------------------------------------------

【例1】英小文字＋数字、16文字のパスワードを1つ作る
passgen.exe -k lower digits

【例2】英大文字・小文字・数字・記号を含む
20文字のパスワードを3つ作る
passgen.exe -l 20 -k lower upper digits symbols -n 3

【例3】記号を含めないパスワードを作る
passgen.exe -k lower upper digits

--------------------------------------------------
パスワードの取り扱いについて
--------------------------------------------------
・生成されたパスワードはファイル保存・送信・記録されません。
・表示された内容は、画面を閉じると失われます。
・作者側でパスワードを復元・確認することはできません。
・生成後の管理はご自身の責任で行ってください。
