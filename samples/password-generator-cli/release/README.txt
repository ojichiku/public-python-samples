==================================================
Password Generator CLI
==================================================

Windows向けのパスワード生成ツール（CLI）です。

【起動方法】
1) コマンドプロンプトを開く
2) app フォルダへ移動
   cd app
3) 実行例
   passgen.exe -l 20 -k digits lower upper symbols -n 3

【主なオプション】
-l / --length : パスワード長
-k / --kinds  : digits, lower, upper, symbols
-n / --count  : 生成する個数
