==================================================
Password Generator GUI
==================================================

Windows向けのパスワード生成ツール（GUI）です。
本ツールは Python で作成し、Nuitka により実行ファイル化しています。
本ツールは無償で配布されます。

--------------------------------------------------
用途について
--------------------------------------------------
・個人利用、学習用途向けのパスワード生成ツールです。
・本ツールで生成したパスワードの安全性を保証するものではありません。
・重要なシステムや業務用途での使用は、ご自身の判断で行ってください。

--------------------------------------------------
配布物の内容
--------------------------------------------------
本ZIPには以下が含まれます。

PasswordGeneratorGUI
├ README.txt          本ファイル
├ LICENSE             本ツールのライセンス（MIT）
└ app/
   └ passgen-gui.exe  本ツールの実行ファイル

※ ソースコードは同梱していません。

--------------------------------------------------
起動方法
--------------------------------------------------
1) app フォルダへ移動
   cd app
2) 実行
   passgen-gui.exe

※ ダブルクリックで起動しても問題ありません。

--------------------------------------------------
使い方（GUI操作）
--------------------------------------------------
・長さ、生成数、文字種（数字/小文字/大文字/記号）を設定します。
・「紛らわしい文字を除外」を ON にすると 0 O 1 I l を除外します。
・「生成」で結果を表示し、選択コピー / 全コピーが可能です。
・「クリア」で結果を空にします。

--------------------------------------------------
パスワードの取り扱いについて
--------------------------------------------------
・生成されたパスワードはファイル保存・送信・記録されません。
・表示された内容は、画面を閉じると失われます。
・作者側でパスワードを復元・確認することはできません。
・生成後の管理はご自身の責任で行ってください。
