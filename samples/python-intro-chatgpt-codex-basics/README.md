# python-intro-chatgpt-codex-basics

Python入門記事「ChatGPTとCodexでできること」を補足する公開サンプルです。

含まれているファイルは次の通りです。

* `chatgpt_nameerror_sample.py`: ChatGPT に `NameError` の説明を依頼するときのサンプル
* `codex_total_before.py`: Codex に整理を依頼する前のコード
* `codex_total.py`: Codex に整理してもらった後のイメージコード

## 実行方法

```bash
python chatgpt_nameerror_sample.py
python codex_total_before.py
python codex_total.py
```

`chatgpt_nameerror_sample.py` は、意図的に `NameError` が出る例です。
そのため、実行するとエラーになります。

`codex_total_before.py` と `codex_total_after.py` は、そのまま実行できます。
