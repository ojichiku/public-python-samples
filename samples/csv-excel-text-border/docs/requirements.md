# Codexへの依頼文

Pythonで、CSVファイルをExcelファイルに変換するコマンドラインツールを作成してください。

ツール名は `csv-excel-text-border` とします。

目的は、CSVの値を変えずに、Excelで確認しやすい形式に変換することです。

## 作成するもの

以下のファイルを作成してください。
requirements.txtを作りますが、実際はuvを使用して実装を行ってください。

・AGENTS.md
・PLANS.md
・csv_to_excel.py
・requirements.txt
・sample.csv
・README.md

最初に `AGENTS.md` と `PLANS.md` を作成してください。
その後、`AGENTS.md` と `PLANS.md` の内容に従って実装してください。

## ツールの仕様

このツールは、コマンドラインでCSVファイルを指定して実行します。

たとえば、以下のように実行します。

```bash
python csv_to_excel.py sample.csv
```

`sample.csv` を指定した場合、同じフォルダに `sample.xlsx` を作成してください。

## 変換ルール

CSVファイルの内容をExcelファイルに出力してください。

変換ルールは以下です。

・CSVの1行目は、Excelの1行目に出力する
・CSVの2行目以降は、Excelの2行目以降に出力する
・すべてのセルの値は文字列として出力する
・先頭の0が消えないようにする
・数値、日付のように見える値も、CSVの値をそのまま文字列として出力する
・Excelの出力範囲には罫線を引く
・罫線は、データが入っているすべてのセルに適用する
・1行目のヘッダー行は太字にする
・列幅は、内容が確認しやすいように自動調整する

## 罫線について

今回のツールでは、Excelに出力したときに確認しやすくすることが重要です。

そのため、CSVをExcelに変換するだけでなく、出力したセル範囲に罫線を引いてください。

罫線の対象は、ヘッダー行を含むすべてのデータ範囲です。

たとえば、CSVが5列10行の場合、ExcelのA1からE10までに罫線を引いてください。

## エラー処理

以下のエラー処理を入れてください。

・コマンドライン引数が指定されていない場合は、使い方を表示する
・指定されたCSVファイルが存在しない場合は、エラーメッセージを表示する
・指定されたファイルの拡張子が `.csv` ではない場合は、エラーメッセージを表示する
・変換に失敗した場合は、エラーメッセージを表示する

## 出力メッセージ

変換に成功した場合は、以下のようなメッセージを表示してください。

```text
Excelファイルを作成しました: sample.xlsx
```

## 使用するライブラリ

CSVの読み込みには、Pythonの標準ライブラリを使用してください。

Excelファイルの作成には `openpyxl` を使用してください。

`requirements.txt` には、必要なライブラリを記載してください。

## sample.csv の作成

動作確認用の `sample.csv` も作成してください。

`sample.csv` には、Excelで自動変換されやすい値を含めてください。

たとえば、以下のようなデータを入れてください。

・先頭に0があるコード
・郵便番号
・電話番号
・日付のように見える値
・数値のように見える文字列
・商品コード
・金額

サンプルCSVの内容例は以下です。

```csv
id,customer_code,postal_code,phone,order_date,product_code,amount
1,00123,012-3456,090-0123-4567,2026/07/01,A-0001,1000
2,00045,001-0001,03-1234-5678,2026/07/02,B-0020,2500
3,01000,100-0001,080-9999-0000,2026/07/03,C-0300,0300
```
