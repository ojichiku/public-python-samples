# PLANS.md

## 作成するファイル一覧

- `AGENTS.md`
- `PLANS.md`
- `csv_to_excel.py`
- `requirements.txt`
- `sample.csv`
- `README.md`
- `pyproject.toml`

## 実装手順

1. `AGENTS.md` と `PLANS.md` を作成する。
2. `pyproject.toml` と `requirements.txt` に `openpyxl` の依存関係を記載する。
3. `sample.csv` を作成する。
4. `csv_to_excel.py` を実装する。
5. `README.md` にセットアップ方法と実行方法を書く。
6. `uv` で依存関係をインストールして動作確認する。

## CSV 読み込み処理

- コマンドライン引数で CSV ファイルのパスを受け取る。
- ファイルが存在することを確認する。
- 拡張子が `.csv` であることを確認する。
- Python 標準ライブラリの `csv` で読み込む。
- UTF-8 BOM 付き CSV も読めるように `utf-8-sig` で読み込む。

## Excel 出力処理

- `openpyxl.Workbook` で新しい Excel ブックを作成する。
- CSV の 1 行目を Excel の 1 行目へ出力する。
- CSV の 2 行目以降を Excel の 2 行目以降へ出力する。
- 出力ファイル名は入力 CSV と同じフォルダの `.xlsx` にする。

## 文字列として出力する処理

- すべての値を Python の文字列としてセルに設定する。
- セルの表示形式を文字列に設定する。
- 空のセルも空文字列として扱う。

## 罫線を引く処理

- データが入っている範囲を対象にする。
- ヘッダー行を含むすべてのセルに細い罫線を設定する。
- CSV が 5 列 10 行なら、Excel の A1 から E10 まで罫線を引く。

## 列幅を調整する処理

- 各列の最大文字数を調べる。
- 最大文字数に少し余白を足して列幅を設定する。
- 長すぎる値で列幅が広がりすぎないよう、上限を設ける。

## エラー処理

- コマンドライン引数がない場合は使い方を表示する。
- 指定された CSV ファイルが存在しない場合はエラーメッセージを表示する。
- 指定されたファイルの拡張子が `.csv` ではない場合はエラーメッセージを表示する。
- CSV が空の場合はエラーメッセージを表示する。
- 変換に失敗した場合はエラーメッセージを表示する。

## 動作確認手順

1. `uv sync` を実行する。
2. `uv run python csv_to_excel.py sample.csv` を実行する。
3. `sample.xlsx` が作成されることを確認する。
4. 先頭の 0 が消えないことを確認する。
5. 日付のような値が自動変換されないことを確認する。
6. CSV の値が文字列として Excel に出力されることを確認する。
7. 出力範囲に罫線が引かれていることを確認する。
8. ヘッダー行が太字になっていることを確認する。
9. 存在しない CSV ファイルを指定した場合にエラーが出ることを確認する。
10. CSV 以外のファイルを指定した場合にエラーが出ることを確認する。
