# AGENTS.md

## 目的

このプロジェクトは、CSV ファイルを Excel ファイルに変換するシンプルなコマンドラインツールです。

CSV の値を変えずに、Excel で確認しやすい形式へ変換することを目的とします。

## 守るルール

- CSV の値を変えずに Excel へ出力する。
- すべての値を文字列として扱う。
- 先頭の 0、日付のように見える値、数値のように見える値を自動変換させない。
- Excel の出力範囲には罫線を引く。
- 罫線はヘッダー行を含むすべてのデータ範囲に適用する。
- シンプルなコマンドラインツールとして作る。
- 不要な機能を増やさない。
- コードは読みやすく、処理の流れが追いやすい形にする。
- エラー時には分かりやすい日本語メッセージを出す。

## 実装方針

- CSV の読み込みには Python 標準ライブラリの `csv` を使用する。
- Excel ファイルの作成には `openpyxl` を使用する。
- 実行形式は `python csv_to_excel.py sample.csv` とする。
- 出力ファイルは入力 CSV と同じフォルダに、同じファイル名の `.xlsx` として作成する。
